# TTS Studio

**Озвучка текстов и книг — прямо на вашем компьютере.**

Вставьте текст или перетащите `.txt`, `.epub` или `.pdf`, выберите голос — получите аудиокнигу.
Локальные движки работают полностью офлайн: ничего из того, что вы озвучиваете, не покидает ваш компьютер.

[Скачать](#скачать) · [Движки](#движки) · [Запуск из исходников](#запуск-из-исходников) · [English](README.md)

## Что умеет

- **Любой текст, любой длины.** Хоть абзац, хоть целый роман. EPUB автоматически
  разбивается на главы: каждая сохраняется отдельным файлом, плюс книга целиком.
- **Четыре движка в одном окне.** Два работают офлайн на вашем железе, два — облачные.
- **Клонирование голоса.** Дайте Chatterbox образец на 5–20 секунд — он прочитает текст этим голосом.
- **Много языков.** Kokoro — 9, Chatterbox — 23, Edge TTS — больше 100.
- **Честный прогресс.** Для длинной книги видно проценты, сколько фрагментов готово,
  сколько времени прошло и сколько ещё осталось.
- **Интерфейс на русском и английском.**
- **Сохранение в WAV и MP3** в любую папку, которую вы укажете.

## Скачать

Возьмите установщик для своей системы на [**странице релизов**](../../releases/latest).

| Система | Файл |
|---|---|
| macOS (Apple Silicon — M1/M2/M3/M4) | `TTS-Studio-<версия>-macOS-arm64.dmg` |
| macOS (Intel) | `TTS-Studio-<версия>-macOS-x86_64.dmg` |
| Windows 10/11 (64-бит) | `TTS-Studio-<версия>-Windows-Setup.exe` |
| Windows (без установки) | `TTS-Studio-<версия>-Windows-portable.zip` |

Установщик небольшой — около 20 МБ. В нём само приложение и два облачных движка,
которые работают сразу. Офлайн-движки весят много, поэтому скачиваются потом и только
если вы сами попросите — на вкладке **Движки** внутри программы.

### Первый запуск

Программа открывается в браузере по адресу `http://127.0.0.1:8766`. Это и есть интерфейс;
сама программа работает в фоне, пока вы её не закроете.

> **Сборки не подписаны цифровой подписью** — сертификат для подписи это платная
> именная подписка у Apple и Microsoft. Обе системы предупредят вас при первом запуске.
> Так выглядит любая неподписанная программа, это не сообщение о вирусе.

**macOS** — нажмите на программу в «Программах» правой кнопкой (или Control + клик),
выберите **Открыть** и подтвердите. Нужно только один раз. Если macOS всё равно
отказывается:

```bash
xattr -dr com.apple.quarantine "/Applications/TTS Studio.app"
```

**Windows** — SmartScreen покажет «Система Windows защитила ваш компьютер».
Нажмите **Подробнее**, затем **Выполнить в любом случае**.

Если не хотите доверять готовому файлу — [запустите из исходников](#запуск-из-исходников):
это тот же самый код и всего две команды.

## Движки

| Движок | Работает | Голоса | Языки | Размер | Требует |
|---|---|---|---|---|---|
| **Kokoro** | офлайн | 51 готовый | 9 | ~900 МБ | — |
| **Chatterbox** | офлайн | клонирует ваш образец | 23 | 3,5–6 ГБ | образец голоса |
| **Edge TTS** | облако | 300+ | 100+ | — | интернет |
| **ElevenLabs** | облако | из вашего аккаунта | 30+ | — | API-ключ |

**Kokoro** — правильный выбор по умолчанию для длинной книги: быстрый, стабильный,
звучит как диктор. **Chatterbox** нужен, когда голос важнее скорости: он заметно
медленнее и требует чистого образца для клонирования.

На Apple Silicon оба офлайн-движка считаются на видеоядре через MLX. На Windows, Linux
и Intel-маках вместо этого используются ONNX Runtime и PyTorch. Программа сама выбирает
подходящий вариант и показывает, какой именно выбрала.

### Как установить офлайн-движок

Откройте вкладку **Движки** и нажмите **Установить**. Программа скачает отдельную сборку
Python и веса моделей в свою папку с данными, показывая прогресс. В систему ничего не
устанавливается, а кнопка **Удалить** убирает всё обратно.

Все данные лежат в одной папке — удалите её, чтобы снести программу начисто:

| Система | Папка |
|---|---|
| macOS | `~/Library/Application Support/TTS Studio` |
| Windows | `%LOCALAPPDATA%\TTS Studio` |
| Linux | `~/.local/share/tts-studio` |

### ElevenLabs

ElevenLabs — платный облачный сервис, нужен ваш собственный ключ:

1. Войдите на [elevenlabs.io](https://elevenlabs.io) и откройте
   [**Settings → API Keys**](https://elevenlabs.io/app/settings/api-keys).
2. Создайте ключ и скопируйте его.
3. В TTS Studio откройте **Настройки**, вставьте ключ и нажмите **Проверить и сохранить**.
   Программа проверит ключ и покажет ваш тариф и остаток символов.
4. Вернитесь на вкладку **Озвучка**, выберите ElevenLabs и нажмите **Загрузить мои голоса**.

Ключ хранится в вашей папке с данными на вашем компьютере. Он никуда не отправляется,
кроме самого ElevenLabs, и программа никогда не отдаёт его обратно в браузер.

## Запуск из исходников

Работает на macOS, Windows и Linux. Нужен Python 3.10 или новее.

```bash
git clone https://github.com/Morpheusmatrixbot/tts-studio.git
cd tts-studio
pip install -r requirements.txt
python -m ttsstudio
```

Браузер откроется на `http://127.0.0.1:8766`. Офлайн-движки ставятся с вкладки
**Движки** точно так же, как в собранной программе — код один и тот же.

Полезные ключи:

```bash
python -m ttsstudio --port 9000     # другой порт
python -m ttsstudio --no-browser    # не открывать браузер
```

## Советы для длинных книг

- **«Слов в одном фрагменте»** (в разделе *Дополнительно*) — главная ручка качества.
  Нейросети «плывут» на длинных кусках, поэтому текст читается фрагментами и потом
  склеивается. Меньше фрагмент — надёжнее, больше — речь звучит связнее. 55 это разумный
  баланс, для Chatterbox безопаснее 30–40.
- **Сначала оцените время.** После загрузки файла видно количество слов и примерную
  длительность звука. На Mac mini M4 замерено: Kokoro выдал 3 минуты 10 секунд звука за
  24 секунды — примерно в 8 раз быстрее прослушивания, то есть роман на 100 тысяч слов
  займёт около 35 минут. Chatterbox работает примерно в реальном времени, поэтому та же
  книга — задача на ночь.
- **Отмена безопасна.** При остановке все уже готовые главы сохраняются.

## Собрать установщики самому

```bash
pip install -r requirements.txt pyinstaller
python packaging/make_icon.py
pyinstaller packaging/ttsstudio.spec --noconfirm

bash packaging/make_dmg.sh 1.0.0                       # macOS → dist/*.dmg
iscc /DAppVersion=1.0.0 packaging\windows\installer.iss # Windows → dist/*Setup.exe
```

PyInstaller не умеет собирать под чужую систему, поэтому каждый установщик собирается на
своей ОС. Файл [`.github/workflows/build.yml`](.github/workflows/build.yml) делает это
все сразу на серверах GitHub и прикладывает результат к релизу при публикации тега `v*`.

## Приватность

Kokoro и Chatterbox работают целиком на вашей машине — текст никуда не передаётся.
Edge TTS и ElevenLabs облачные, поэтому отправленный им текст по определению покидает
компьютер; если это важно, пользуйтесь офлайн-движком. Программа слушает только
`127.0.0.1` и отклоняет запросы не с вашего компьютера.
